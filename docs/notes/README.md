| [../analysis/2026-09-10-campaign-07-wrapup.md](../analysis/2026-09-10-campaign-07-wrapup.md) | **Campaign 07, 3 of 6 arms, and the one result that replicated.** Two models — `claude-sonnet-5` and `gemini-3.1-pro-preview` — agree on exactly two of five metrics: `safety_v1` up (a criterion) and `instruction_following_v1` down (**the holdout, absent from the sampler config**), the second worse on the second model. | [../analysis/2026-09-09-c07-first-calibrated-result.md](../analysis/2026-09-09-c07-first-calibrated-result.md) | **The first result calibrated against a concurrent control, and the first where the calibration changes the answer.** `c07-sonnet5`: safety +0.154, all four capability metrics down, average -0.011 — *inside* the floor, so a scalar report reads "no change" on a run that traded capability for safety. ## Conventions for These Notes

- Check for an existing note on the topic and **update it** rather than adding a
  duplicate. Delete notes that turn out to be wrong or stale.
- Notes record what was true **when written** — each carries a "verified on" date. If a
  note names a file, flag, or command, re-verify it still exists before acting on it.
- Do not restate what the repo already records. Capture the thing you would otherwise
  rediscover the hard way.
